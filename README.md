## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- Angular CLI

### Installation

```bash
npm install -g @angular/cli

# Clone the repository
git clone https://github.com/your-username/akshay-portfolio.git

# Go into the project
cd akshay-portfolio

# Install dependencies
npm install

# Start the development server
ng serve

```
